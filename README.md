# 📋 Task Management System (Stack vs Queue)

A Java console application that demonstrates the practical implementation of fundamental Data Structures. The project efficiently manages tasks by prioritizing **Urgent Tasks** using a **Stack** (Last-In, First-Out) and **Regular Tasks** using a **Queue** (First-In, First-Out).

## 🚀 Key Features

- **Urgent Task Manager (Stack):** - Implemented using an Array-based Stack.
  - Operations: Push (Add), Pop (Handle), Peek, and Display all.
  - Logic: Follows LIFO (Last-In, First-Out) for immediate task handling.
- **Regular Task Manager (Queue):** - Implemented using a Singly Linked List.
  - Operations: Enqueue (Add), Dequeue (Process), Peek, and Display all.
  - Logic: Follows FIFO (First-In, First-Out) to ensure tasks are processed in order.
- **Interactive CLI:** A menu-driven interface allowing users to manipulate tasks dynamically.

## 🛠️ Technologies & Concepts

- **Language:** Java
- **Data Structures:** - **Stack:** Array-based implementation with `top` pointer management.
  - **Queue:** Linked List-based implementation with `front` and `rear` pointers.
- **OOP:** Encapsulation and modular class design.

## 💻 Project Structure

- `Main.java`: The driver class with the menu loop and test cases.
- `URGENTtasks.java`: Manages urgent tasks using a stack array.
- `REGULARtasks.java`: Manages regular tasks using a linked list.
- `Node.java`: The building block for the linked list queue.
